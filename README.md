# Concurrent Search Bot

Учебный Telegram-бот на aiogram 3.

Планируемые источники:
- Wikipedia
- GitHub
- Stack Overflow

Цель проекта — изучить конкурентное выполнение сетевых операций,
частичные отказы, таймауты и ограничение конкурентности.

## Текущее состояние

- Подготовлено окружение и структура Python-проекта.
- Реализовано базовое исполнение бота, отвечающее на сообщение. 
- Последовательно реализованы три системы обращения к требуемым API.
- Протестировано время выдачи запросов без конкурентного исполнения -
``` 
Wikipedia: поиск занял 11.90 с
GitHub: поиск занял 4.50 с
Stack Overflow: поиск занял 2.45 с
```
- Протестировано время выдачи запросов с конкурентным исполнением.
- Введён SearchService с конкурентным выполнением запросов по средствам gather(), выдача результата происходит по времени самого долгого запроса.

## Подготовка
```bash
python -m venv .venv
source .venv/bin/activate
python -m pip install -e .
```
